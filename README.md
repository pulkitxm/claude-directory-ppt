# Claude Directory — Show & Tell deck

A [reveal.js](https://revealjs.com) presentation for **Claude Directory** — a growing library of UI experiments built with Claude (453 projects, free & open source).

- 🔗 Live directory: https://pulkit.page/claude-directory
- ⭐ Main repo: https://github.com/pulkitxm/claude-directory

## View it
Open `index.html` in any browser. Press **F** for fullscreen, arrow keys to navigate, **Esc** for the slide overview.

The promo video (`promo-x.mp4`) is embedded in the deck; this repo also includes the standalone file.

Built with Claude.
